# 每日记录的情绪集合必须包含正面情绪

每日记录的情绪集合包含 10 种情绪：6 种负面（沿用 SOS：焦虑/愤怒/悲伤/惊恐/过载/疲惫）+ 4 种正面（平静/开心/感激/放松）。SOS 场景仍只用负面子集，但每日记录必须允许正面情绪。

理由：每日记录是日常陪伴功能，用户不是天天崩溃的。如果每日记录只允许负面情绪，会变成每日负面强化器——强迫用户每天从"我有什么问题"的列表里选，放大反刍倾向（rumination），这在心理健康领域是临床上有害的设计。允许正面情绪让用户记录完整的自己，也让洞察页的语义从"我的问题分布"升级为"我的情绪全貌"（能看到"这周有 2 天是平静的"）。不要为了"精简"而删掉正面情绪——它们的缺失不是优化，是价值观倒退。
