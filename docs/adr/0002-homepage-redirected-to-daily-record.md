# 首页主入口从 SOS 改为每日记录，SOS 降级为次级按钮

首页原本 100% 是 SOS 急救入口（巨大"开始急救"按钮 + "60秒情绪急救"副标题），这使非危机用户打开 App 时产生认知失调（"我现在又没崩溃，点这个干嘛？"）后退出——这是留存的根本障碍。我们将首页主体改为"今天感觉怎么样？"+ 每日记录入口，SOS 降级为一个仍然醒目但不再是视觉焦点的次级 CTA（"现在很难受？→ 立即急救"）。

理由：产品定位已从"情绪急救工具"演进为"急救 + 日常陪伴 + 洞察"。按使用频次，日常陪伴 > 危机急救，首页权重应反映这一分布。SOS 降级不等于消失——它仍保证危机场景的可达性（首页可找到），只是不再让非危机用户每天都面对一个"你崩溃了吗"的按钮。未来读者看到 `HomePage.tsx` 不是 SOS 主入口时，应理解这是有意的留存策略，而非首页被"改坏了"。
